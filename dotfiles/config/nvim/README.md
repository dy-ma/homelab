# Neovim shortcuts

The leader key is Space. Pause after pressing Space to display available
WhichKey shortcuts.

## Everyday

- `Space w` — save
- `Space q` — close the current window
- `Ctrl-h/j/k/l` — move between split windows
- `gc` — comment using Neovim's built-in comment operator
- `[d` / `]d` — previous/next diagnostic
- `Space e` — explain the current diagnostic

## Find with Telescope

- `Space f f` — files
- `Space f g` — text inside files
- `Space f b` — open buffers
- `Space f r` — recent files
- `Space f h` — Neovim help
- `Space f k` — configured keymaps

## Git

- `[h` / `]h` — previous/next changed hunk
- `Space g p` — preview changed hunk
- `Space g b` — blame the current line

Run `:Lazy` to inspect or update plugins and `:checkhealth` to diagnose the
editor.
